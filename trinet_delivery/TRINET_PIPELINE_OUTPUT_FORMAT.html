Trinet delivery pipeline / format decision

Preserve the capture first. Optimize delivery second.

The nine references below solve different problems: bulk video streaming, commercial catalogue QA, multimodal loading, native asynchronous capture, ground-truth evaluation, reproducible export, human/robot normalization, cross-dataset robot training, and human-to-robot action transfer. Trinet needs a verified source package before any training representation.

01 / Raw

Native Trinet files

MP4, IMU, VTS, optional TEL, JSON, and embedded metadata remain byte-identical.

02 / Decode

Native-rate IMU

Confirmed IMU fields and original timestamps become one typed table without interpolation.

03 / Verify

Traceable QC

Measured facts, deterministic diagnoses, transformations, and human decisions stay distinct.

04 / Deliver

Inspectable episodes

One capture folder can be opened by tools, the CLI, or the shared review service.

Meaning of each layer

README.mdHuman guide to fields, limitations, inspection, and loading.
manifest.csvOne row per capture with source paths, hashes, measured facts, and QC disposition.
raw/Authoritative source bytes. Hashes establish identity, not quality.
imu.parquetConfirmed typed IMU rows at the native rate. No interpolation or silent repair.
qc.jsonDistinct sections for facts, diagnoses, transformations, and human decision.

Published formats / native capture to enriched delivery

Capture fidelity and derived evidence

These references separate native sensor recording from derived research outputs. That separation is the decisive pattern for Trinet.

Company / referenceExact published format and access pathWhy this choice fits that productCombined lesson and Trinet decision
Official format + SDKMeta Project AriaVRS One .vrs stores typed per-sensor Configuration, State, and Data records for camera, audio, IMU, magnetometer, and other streams. Configuration blobs carry static sensor information; calibration is addressed by stream label. Same-device sensors share DEVICE_TIME; APIs query by timestamp and declared time domain. MPS outputs stay separate. Meta documents VRS for multimodal XR recording, large files, timestamp-order playback, and random access. It preserves asynchronous native rates while an integrated device supplies stream IDs, calibration, one capture clock, integrity tooling, and timestamp-query APIs. Adopt: explicit clock domains, native-rate streams, capture-versus-arrival semantics, configuration/calibration provenance, integrity checks, and timestamp queries.
Do not convert Trinet to VRS: repacking cannot recreate Aria hardware guarantees and would promote a derived container above original sidecars.
Official dataset + toolkitMeta HOT3DFull sequences + HOT3D-Clips Full folders include recording.vrs, metadata, object definitions, headset trajectory, MANO/UmeTrack trajectories, boxes, MPS outputs, and timestamp/stream mask CSVs. Separately, 3,832 five-second WebDataset clips contain 150 keyed frames, three camera JPEGs per frame, camera/hand/hand-crop/object/info JSON, and shared hand-shape data. The full VRS-based dataset supports sequence research; fixed WebDataset clips serve BOP and hand-tracking evaluation. Independent masks encode pose availability, visibility, exposure, and manual-QA pass, so consumers compose a validity rule without deleting annotations or confusing availability with accuracy. Adopt: property-specific validity, timestamp-level evidence, separate manual decisions, and a hard boundary between full recordings and derived clips.
Do not copy: hand/object ground truth and benchmark packaging are future enrichment or adapters, not Trinet v1 source evidence.
Official dataset + open SDKFPV LabsStera-10M + Stera SDK The iPhone app records RGB, depth, pose/intrinsics, IMU, tracking, transforms, map, and trajectory as ROS2 topics in raw MCAP. Published sessions contain rgb.mp4, annotation.hdf5, hierarchy.json, mesh.ply, thumbnail, six calibration files, and full/preview Rerun recordings. HDF5 separates depth, pose, native-rate IMU, hand pose, and metadata; aligned arrays include validity. The documented loop targets reproducible hour-plus multimodal collection on commodity iPhone Pro hardware. MCAP serves capture; HDF5 supports selective numeric reads; MP4 remains playable; PLY carries geometry; calibration is explicit; Rerun supplies review; the Apache-licensed SDK reproduces processing. Adopt: raw/processed separation, natural-rate IMU, explicit validity/units/frames, model provenance, self-contained sessions, and review artifacts.
Do not copy as canonical: Trinet lacks Stera's derived modalities. Stera docs and current exporter also conflict on a depth timestamp and hand coordinate framing, proving nominal schemas still require file validation.
Shared pattern: Aria preserves integrated-device capture; HOT3D layers validity and benchmarks on top; Stera publishes a capture-to-export path. None justifies replacing uncertain Trinet originals with a more polished derived container.

Published formats / downstream training representations

When normalization becomes useful

These rows belong later in the pipeline. They require calibrated motion, robot trajectory semantics, or a declared human-to-robot action representation.

Company / referenceExact published format or representationWhy this choice fits that productCombined lesson and Trinet decision
Official code + convertersGeorgia TechEgoVerse / EgoMimic Current storage is one <episode_hash>.zarr/ v3 group, a same-hash MP4 preview, and a PostgreSQL catalogue row. Frame-indexed arrays include JPEG-byte images.front_1, head/wrist/EE poses, optional MANO points, RGB timestamp values, and annotations; root metadata carries embodiment, total_frames, and mandatory 3x4 intrinsics. The Aria converter combines VRS with MPS hand/SLAM CSVs and removes invalid-pose frames. The repository co-trains on human and robot demonstrations. One chunked episode interface and catalogue batch images, poses, actions, annotations, and overlays; embodiment metadata selects the representation. total_frames bounds padded tails and absent modalities are normally omitted. Adopt later: explicit source/embodiment, geometry-gated calibration, authoritative length, versioned conversion, and catalogue-backed views.
Do not copy for v1: it needs SLAM/hand actions, aligns to video frames, omits high-rate IMU, and drops invalid frames. Current guide/code also disagree on timestamp domain and calibration provenance.
Official unified schemaGoogle DeepMindOpen X-Embodiment / RLDS Open X distributes versioned TFDS directories, typically sharded TFRecord files plus dataset/feature metadata, loaded from GCS or local storage. RLDS is the logical read-time schema, not one container: episode dictionaries contain metadata and nested ordered steps. Steps require is_first/is_last; observation, action, reward, terminal, discount, fields, and shapes remain dataset-specific. Each native robot dataset uses its own TFDS builder and feature mapping, then exposes one episode/step interface for downstream mixtures. Training can interleave heterogeneous embodiments while retaining contributor-specific observations/actions. RLDS does not impose one universal action vector. Adopt only as a buyer adapter: useful after genuine episode, observation, action, state, task, and terminal semantics exist.
Do not use as canonical: Trinet lacks robot actions/rewards/termination. Inventing fields or resampling IMU merely to make steps creates false semantics and hides native evidence.
Papered representation, no public packageNVIDIA GEAREgoScale No public on-disk dataset schema or loader is released; the official page says GitHub “Coming Soon.” The paper defines 30 FPS RGB plus estimated camera SE(3) and 21 hand-keypoint transforms, converted to relative wrist motion and optimization-retargeted 22-DoF Sharpa targets. Precision/alignment stages add Vision Pro, Vive wrist pose, Manus 25-joint transforms, and synchronized views. EgoScale is a cross-embodiment training recipe, not neutral delivery. Relative wrist motion removes global camera movement; retargeted joints provide finger supervision; small embodiment adapters and aligned human/robot data connect that shared representation to executable control. Future lesson: pair raw scale with precision anchors; declare coordinates, target embodiment, validity, provenance, and evaluation for wrist/finger actions.
Do not call it a format: public storage fields are undocumented, transformations are model-specific, and the paper describes noisy off-the-shelf estimates.
